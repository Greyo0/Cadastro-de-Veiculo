# Prova de Projeto 1

Esse projeto é uma aplicação de cadastro de veículo feita para a avaliação do Git, GitHub e GitFlow.

O site foi tematizado em Ordem Paranormal.

## Sequência de Operações

1. Criado um repositório público para o projeto

2. Preparado o repositório local e conectado ao repositório remoto

3. Criado uma versão inicial do projeto: Cadastro de Veículo por Cor e Tipo do Veículo. Aplicação tematizada de Ordem Paranormal

4. Inicializado e configurado o git flow

5. Criada feature para cadastro com modelo e placa

6. Realizado dois commits diferentes, um para cada parte (um para modelo e um para placa)
